# Original naming, no Riot IP

Mechanics may mirror the MOBA genre, but every name in the game is original: champions, abilities, sigils, structures, systems. Nothing is copied from League of Legends (no champion names, no spell names such as Flash or Ignite, no structure names such as Nexus, no icons or other Riot assets). The champion theme is fantasy rather than Claude-derived, so the roster can grow without running out of names. Purely generic genre vocabulary (tower, minion, lane, brush, recall, fog of war) stays.

All project content, in the game and in the docs, is written in English from the start.
