# Original naming, no borrowed IP

Mechanics may mirror the MOBA genre, but every name in the game is original: champions, abilities, sigils, structures, systems. Nothing is copied from any other game: no champion names, no spell names, no structure names, no icons or other third-party assets. Beyond names, the repo itself stays free of competitor mentions: research notes that cite other games by name live outside version control (`docs/research/` is gitignored). The champion theme is fantasy rather than Claude-derived, so the roster can grow without running out of names. Purely generic genre vocabulary (tower, minion, lane, brush, recall, fog of war) stays.

All project content, in the game and in the docs, is written in English from the start.

## One noted exception

Taken by the maintainer on 2026-09-09, with the announcer's multikill ladder: the two top
rungs are called **Quadrakill** and **Pentakill**. Unlike "double kill" and "triple kill",
which are generic across the genre and owned by nobody, those two are another game's
coinage, so they are a deliberate departure from the rule above rather than an example of
it. The rule stands everywhere else, and this exception admits no others. The word
"rampage", which had been sitting unremarked on the four-kill rung and is likewise
borrowed, leaves the announcer's table with the recordings that replace it.
